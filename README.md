# MATCH!CORE

Aplicación web para el seguimiento en tiempo real de partidos de fútbol y fútbol sala.

Proyecto final del CFGS Desarrollo de Aplicaciones Web (DAW2D), CPIFP Los Enlaces, curso 2026-27.

## Documentación

La memoria, las entregas de cada tarea y los documentos del módulo se guardan y se editan
únicamente en Google Drive, en la carpeta **proyecto fin de grado**. Este repositorio solo
contiene el código de la aplicación.
